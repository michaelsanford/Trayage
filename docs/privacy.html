Privacy

Trayage has no analytics, no telemetry, no tracking, no user accounts and no servers of its own. It does not collect any data, because there is nowhere for it to send data.

What stays on your device

Everything Trayage stores is kept on your own PC, under %APPDATA%\Trayage, and is never sent to the developer:

  • OAuth tokens. One set per connected account, encrypted with Windows DPAPI so only your Windows account on that PC can read them.
  • Settings. Your poll interval, theme, and the accounts you have connected, along with the repositories each one watches.
  • Logs. A local application log and crash log for troubleshooting. Tokens are never written to them, and Trayage tries to keep account identifiers (your login and user ID on each service) out of them as well.

Where your data goes

Trayage connects directly from your PC to GitHub, Bitbucket and GitLab, signed in as you with the tokens you authorized. It uses them only to read your inbox and to open the pages you click. Each account is only used with its own service. There is no Trayage server in between. Your use of those services is covered by their own privacy policies, not this one.

This website

This site is a static site hosted on GitHub Pages. It sets no cookies, runs no analytics and loads no web fonts. Text is shown in fonts already installed on your device. Two kinds of request go to GitHub, which therefore sees your IP address:

  • Loading the pages themselves, which GitHub Pages serves.
  • On the home page only, one request to the public GitHub API to show the version number of the latest release.

Trayage does not operate GitHub and does not send it any personal data.

Changes

If this policy changes, the change will be visible in the repository's history. If you have a question, open an issue on GitHub.
